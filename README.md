# Circuit-HyperNet: Guiding parameter generation and compositional reasoning with internal computation

Junqi Zhang and Jie Fu

[Read the full article](article_en.md) · [View the PDF](Circuit-HyperNet.pdf) · [Experiment code](https://github.com/hitzjq/Circuit-Hypernet)

The blog describes how a small hypernetwork uses a base model's computation on its first attempt to generate a parameter update for its next attempt.

To read the blog with its original layout, choose **Code → Download ZIP**, extract the archive, and open `index.html` in a browser.
