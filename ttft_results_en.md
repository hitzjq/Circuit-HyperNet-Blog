# Supporting Results: Base-Model TTFT and the Three-Way Comparison

The three archived runs below were evaluated at the same learning rate, `2e-5`, on the ARC-AGI-1 public evaluation split.

| TTFT base model | LoRA initialization | Task-mean selected_exact@2 (%) |
|---|---|---:|
| Original REARC8 base model, step 130 | Standard | 42.625 |
| Direct SFT, step 65 | Standard | 45.875 |
| Direct SFT, step 65 | Generated by S0 step 300 HyperNet | 47.875 |

All three rows use the same adaptation settings: rank 256, alpha 32, and rsLoRA; 128 augmented examples and 128 optimizer calls per task, updating only LoRA and resetting it between tasks. Each route covers 400 tasks, 419 test inputs, and 7,123 view predictions. The primary metric first averages across test inputs within each task and then across the 400 tasks. It is not the input-level fraction 184/419.

For the original base model, 167 tasks scored 1, seven scored 0.5, and 226 scored 0. Their sum is 170.5, giving 42.625% across 400 tasks. The task-score sums for standard and generated initialization on the Direct SFT model are 183.5 and 191.5.

With standard initialization fixed, moving from the original base model to Direct SFT adds 3.25 percentage points. With the Direct SFT base model fixed, HyperNet initialization adds 2 percentage points over standard initialization. The 5.25-point difference between the first and last rows includes both changes and cannot be attributed entirely to HyperNet.

The two-point improvement applies to the matched setting above. An earlier standard-LoRA run reached 49.000% at a different learning rate.
